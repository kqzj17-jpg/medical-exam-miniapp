# 国家医学考试系统（演示）微信小程序

仿「国家医学考试系统」机考流程的**原生微信小程序**（非 uni-app），供口腔 / 医学学员熟悉机考界面与操作。仓库内为本地假数据，**不是**国家医学考试中心官方产品，不接后端、云开发或真实鉴权。

## 演示流程

1. 登录：准考证号 + 证件号（可一键填入示例账号）
2. 答题主界面：倒计时、未答题数、标疑题数、完成考试
3. 分段考试（A1 → A3）：进入下一段后本段不可回看 / 修改
4. 交卷确认（含未答题提示）
5. 成绩页：姓名、准考证、成绩、正确率、用时，可再练一次

## 用微信开发者工具导入预览

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 选择 **导入项目**，目录指向本仓库根目录（含 `app.json` / `project.config.json` 的这一层）
3. `appid` 已填写为占位 **`touristappid`**
   - 可勾选游客模式 / 测试号预览
   - 若需真机预览，在 `project.config.json`（或开发者工具项目设置）里换成你自己的小程序 AppID
4. 编译模式选 **普通编译**，打开模拟器即可走通：首页 → 登录 → 答题 → 交卷 → 成绩

> 本项目不使用 npm 构建、云开发或插件。无需 `npm install`。

### 示例账号（演示）

| 字段 | 值 |
| --- | --- |
| 准考证号 | `202509180010016` |
| 证件号 | `110101199001011234` |
| 姓名 | 演示考生 |

登录页点「一键填入示例账号」可自动写入。任意非空准考证号 + 证件号也可进入（不校验真实考籍），姓名显示为「练习考生」。

默认体验时长 **30 分钟**；演示版可随时点「完成考试」交卷。倒计时到 `00:00` 会自动交卷。

## 机考页操作说明

- **顶部状态栏**：剩余时间、未答题数、标疑题数、「完成考试」
- **题干区**：`题型: A1 / A3`、题号、题干、A–E 五选项；选中高亮并打勾
- **底部**：标疑、转到未答题、转到标疑题、上一题、下一题
- **展开题号**：红 = 未答，灰 = 已答，黄 = 标疑；点击只跳转**当前分段**
- **分段列表**：进入下一段时弹窗文案为  
  「考试将进入下一分段. 进入后本段试题将无法再作修改. 确认要进入下一段考试吗?」  
  按钮为「进入下一段」「继续作答」
- **回看已锁分段**：展示「此题不可回看」
- **交卷**：未答时提示「您还有 X 道试题未答. 确认要完成考试吗?」  
  成功后：「交卷成功！祝您好运！」

A3 为病例组题：同一病例题干下连续作答若干小题，用于演示分段锁定。

## 题库说明

- 本地模块 `data/questions.js`，当前 **42** 道演示题（A1 单选 30 道 + A3 病例组 12 道）
- 每题含 `stem`、`options`（A–E）、`answer`、`explanation`、所属分段，并标记 `demo: true`
- 内容偏口腔执业 / 助理医师备考风格，**非正式真题**，解析仅供界面演示

本地校验（需 Node.js）：

```bash
node scripts/check-bank.js
```
