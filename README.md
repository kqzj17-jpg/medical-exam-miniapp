# 国家医学考试系统（演示）微信小程序

仿「国家医学考试系统」**PC 机考横屏界面**的原生微信小程序（非 uni-app），供口腔 / 医学学员熟悉机考布局与操作。本地假数据，**不是**国家医学考试中心官方产品，不接后端、云开发或真实鉴权。

> **必须横屏预览。** 本版按官方机考左右分栏宽屏还原，不是竖屏手机 App。竖屏下无法对上官方布局。

## 用微信开发者工具横屏预览

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. **导入项目**，目录指向本仓库根目录（含 `app.json` / `project.config.json`）
3. `appid` 为占位 **`touristappid`**（游客模式 / 测试号均可）
4. 编译后**立刻把模拟器转为横屏**：
   - 点击模拟器工具栏的 **旋转** 按钮；或
   - 自定义屏幕：**iPad 横屏**，或 **1280×800** / **1024×768**（更接近考场 PC）
5. 真机预览请将手机横过来。页面已配置 `pageOrientation: landscape`，并会在仍为竖屏时提示旋转

建议不要使用默认竖屏 iPhone 机型直开。宽屏模拟器下左侧考生栏 + 右侧答题区才能一眼看出官方机考系统。

无需 `npm install`，无云开发、无插件。

### 示例账号（演示）

| 字段 | 值 |
| --- | --- |
| 准考证号 | `202509180010016` |
| 证件号 | `110101199001011234` |
| 姓名 | 演示考生 |

登录页点「演示填入」可自动写入。任意非空准考证号 + 证件号也可进入（不校验真实考籍）。

默认体验时长 **30 分钟**（左侧考试时间显示 `09:00-09:30`）；演示版可随时「完成考试」。倒计时到 `00:00:00` 自动交卷。

## 界面还原（对齐官方机考）

横屏工作区为固定左右分栏 + 底部操作条：

- **左侧固定栏**：照片位、姓名、准考证号、考试时间、剩余时间（粉色高亮）、未答题数、标疑题数、「刷新」「完成考试」、红色分段规则、分段列表（如 `A1 : 1~30` / `A3 : 31~42`）
- **右侧答题区**：顶栏「题型: A1」及题型说明；题号+题干；A–E 竖排选项，选中勾选 + 黄底高亮框
- **底部栏**：标疑、转到未答题、转到标疑题、上一题、下一题；题号网格（红未答 / 灰已答 / 黄标疑）+「颜色说明：黄色表示标疑，红色表示未答，灰色表示已答。」

文案与交互保持官方用语：分段锁定弹窗、此题不可回看、未答题交卷提示、「交卷成功！祝您好运！」。

## 演示流程

1. 考生须知 → 登录（准考证号 + 证件号）
2. 机考主界面作答、标疑、题号跳转
3. A1 → A3 分段：进入下一段后本段锁定
4. 完成考试 / 倒计时结束交卷
5. 成绩页

## 目录结构

```text
medical-exam-miniapp/
├── app.js / app.json / app.wxss     # 全局横屏
├── project.config.json              # appid: touristappid
├── data/questions.js                # 42 道口腔风格演示题
├── utils/exam.js                    # 分段锁定、标疑、计时、评分
├── utils/ui.js                      # 横屏与胶囊按钮避让
├── scripts/check-bank.js
└── pages/
    ├── index/                       # 考生须知（横屏窗口）
    ├── login/                       # 官方风格登录
    ├── exam/                        # 机考主界面（核心）
    └── result/                      # 成绩
```

## 题库说明

- `data/questions.js`，**42** 道演示题（A1 单选 30 + A3 病例组 12），全局题号 1~42
- 每题含 `stem`、A–E、`answer`、`explanation`、分段，并标记 `demo: true`

```bash
node scripts/check-bank.js
```
