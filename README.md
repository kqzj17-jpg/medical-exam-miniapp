# 模拟仿真考试系统

本地**仿真练习**微信小程序（原生 WXML/WXSS/JS，非 uni-app）。题目、成绩与登录均为演示数据，**不连接后端**。

界面为**横屏流式布局**（整页 100% 宽高）：左栏约 24%、右栏 flex、底栏固定在可视区内。用 `env(safe-area-inset-*)` 与 `wx.getWindowInfo().safeArea` 避开刘海和底部横条。不使用 transform 缩放，因此不拉扁、也不把题干/底栏裁掉。

底栏是**两段布局**：左区标疑/跳转可换行，右区「上一题」「下一题」`flex-shrink:0`，并覆盖微信 `button` 默认 `min-width`，避免窄横屏把「下一题」挤出屏幕。

## 预览方式

### A. 桌面浏览器

打开 `preview/index.html`（流式布局，窗口拉横即可）。

### B. 微信开发者工具 / 真机

1. 导入本仓库根目录，`appid` 为 **`touristappid`**
2. 必须横屏：已在 `app.json`、各页 json、`<page-meta page-orientation="landscape" />` 声明
3. 模拟器请选横屏机型或自定义 **宽 > 高**
4. **改代码后请重新编译；真机请重新点预览并扫码**，否则仍是旧包

无需 `npm install`。

登录页点「演示填入」。默认 30 分钟，可随时交卷。

## 作答界面

- **上方**：左栏考生信息（照片、姓名、准考证、练习时间、剩余时间、未答/标疑、刷新/交卷、分段）+ 右栏题型条与题干选项
- **下方**：左区标疑、转到未答题、转到标疑题（窄屏可换行）；右区上一题、下一题始终在可视区内可点；红/灰/黄题号

分段锁定后本段不可回看。交卷前展示未答汇总；成绩页可看错题回顾。

## 校验

```bash
node scripts/check-bank.js
node scripts/check-ui.js
```

`check-ui.js` 会检查：产品名、禁用字眼、横屏流式布局、底栏「下一题」横向装得下（含 innerW=600/667/750）。
