# 国家医学考试系统（演示）微信小程序

仿「国家医学考试系统」**PC 机考界面**的原生微信小程序（非 uni-app）。本地假数据，**不是**官方产品。

界面按官方机考 **1280×800** 绘制（左栏 + 右栏 + 底栏），运行时按窗口宽、高**分别** `scaleX` / `scaleY` 拉伸铺满可视区域，不留左右/上下大块灰边（比例可轻微拉伸）。

## 预览方式

### A. 桌面浏览器（不装开发者工具也能看布局）

用浏览器直接打开：

```text
preview/index.html
```

缩放规则与小程序相同：按窗口宽高分别拉伸铺满。

### B. 微信开发者工具（完整作答）

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. **导入项目**，目录为本仓库根目录（含 `app.json`）
3. `appid` 为 **`touristappid`**（游客模式即可）
4. 普通编译后即可：须知 → 登录 → 机考 → 交卷 → 成绩

**必须横屏。** 本项目已在 `app.json`（顶层 + `window`）、每个页面 json、以及每个页面 `<page-meta page-orientation="landscape" />` 中声明横屏。界面按窗口拉伸铺满，不出现大块 letterbox 灰边。

开发者工具模拟器请选**横屏机型**，或自定义分辨率 **宽 > 高**（推荐 **1280×800** / 1280×720）。  
仅改 `pageOrientation` 时，若模拟器窗口仍竖着，需手动切换为横屏设备/点模拟器旋转；否则看起来仍像竖屏外壳。真机请将手机横过来。

无需 `npm install`，无云开发、无插件。

## 作答系统布局（对照官方操作指南）

作答系统分为上下两个区域：

- **上方**：左侧考生信息栏 + 右侧作答区域  
  照片、姓名、准考证号、考试时间、剩余时间（粉色高亮）、未答题数、标疑题数、刷新 / 完成考试、红色分段规则、分段列表（`A1 : 1~30` / `A3 : 31~42`）  
  顶栏「题型: A1」及说明；题干；A–E 竖排，选中勾选 + 黄底高亮框
- **下方**：试题导航列表  
  标疑、转到未答题、转到标疑题、上一题、下一题  
  题号色块：红未答 / 灰已答 / 黄标疑  
  「颜色说明：黄色表示标疑，红色表示未答，灰色表示已答。」

分段锁定弹窗、此题不可回看、未答题交卷提示、「交卷成功！祝您好运！」保持官方用语。
