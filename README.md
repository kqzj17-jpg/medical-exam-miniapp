# 国家医学考试系统（演示）微信小程序

仿「国家医学考试系统」**PC 机考界面**的原生微信小程序（非 uni-app）。本地假数据，**不是**官方产品。

界面为**横屏流式布局**（整页 100% 宽高）：左栏约 24%、右栏 flex、底栏固定在可视区内。用 `env(safe-area-inset-*)` 与 `wx.getWindowInfo().safeArea` 避开刘海和底部横条。不使用 1280×800 transform 缩放，因此不拉扁、也不把题干/底栏裁掉。

底栏是**两段布局**：左区标疑/跳转可换行，右区「上一题」「下一题」`flex-shrink:0`，并覆盖微信 `button` 默认 `min-width`，避免窄横屏把「下一题」挤出屏幕。

## 预览方式

### A. 桌面浏览器

打开 `preview/index.html`（流式布局，窗口拉横即可）。

### B. 微信开发者工具 / 真机

1. 导入本仓库根目录，`appid` 为 **`touristappid`**
2. 必须横屏：已在 `app.json`、各页 json、`<page-meta page-orientation="landscape" />` 声明
3. 模拟器请选横屏机型或自定义 **宽 > 高**
4. **本次改了底栏布局。请重新编译；真机请重新点预览并扫码**，否则仍是旧包，「下一题」还会被挤出屏幕

无需 `npm install`。

## 作答系统布局

- **上方**：左栏考生信息（照片、姓名、准考证、考试时间、粉底剩余时间、未答/标疑、刷新/完成考试、分段）+ 右栏题型条与题干选项
- **下方**：左区标疑、转到未答题、转到标疑题（窄屏可换行）；右区上一题、下一题始终在可视区内可点；红/灰/黄题号；颜色说明

分段锁定、「此题不可回看」、交卷未答提示、「交卷成功！祝您好运！」保持官方用语。

## 校验

```bash
node scripts/check-bank.js
node scripts/check-ui.js
```

`check-ui.js` 会在 844×390、926×428、667×375、扣除刘海 innerW=600、1280×800 下检查：安全区内标题栏 + 左栏 + 题干区 + 底栏高度均为正；并估算底栏 **右区两按钮宽度 + 左区最小宽度 ≤ innerW**。另模拟 innerW=600/667/750，「下一题」必须 complete。未覆盖微信 `button` 默认 `min-width` 或改回五按钮横排时脚本不通过。
