# 模拟仿真考试系统

本地**仿真练习**微信小程序（原生 WXML/WXSS/JS，非 uni-app）。题目、成绩与登录均为演示数据，**不连接后端**。

- **说明页 / 登录页：竖屏**，方便输入准考证号和证件号
- **作答页 / 成绩页：横屏**流式机考界面（左栏约 24%、底栏两段，「上一题 / 下一题」不被挤出）

用 `env(safe-area-inset-*)` 与 `wx.getWindowInfo().safeArea` 避开刘海。不使用 transform 缩放。

## 预览方式

### A. 桌面浏览器

打开 `preview/index.html`（默认竖屏登录；`?exam=1` 看横屏作答）。

### B. 微信开发者工具 / 真机

1. 导入本仓库根目录，`appid` 为 **`touristappid`**
2. 说明/登录为竖屏，进入作答后横屏（页面 json + `<page-meta>` + `wx.setPageOrientation`）
3. 模拟器请分别用竖屏预览登录、横屏预览作答
4. **改代码后请重新编译；真机请重新点预览并扫码**，否则仍是旧包

无需 `npm install`。

### 示例账号

| 字段 | 值 |
| --- | --- |
| 准考证号 | `202509180010016` |
| 证件号 | `110101199001011234` |
| 姓名 | 演示考生 |

登录页点「演示填入」。默认 30 分钟，可随时交卷。

## 作答界面

- **上方**：左栏考生信息 + 右栏题型条与题干选项
- **下方**：左区标疑/跳转可换行；右区上一题、下一题始终可见；红/灰/黄题号

分段锁定后本段不可回看。交卷前展示未答汇总；成绩页可看错题回顾。

## 校验

```bash
node scripts/check-bank.js
node scripts/check-ui.js
```

`check-ui.js` 会检查：产品名、禁用字眼、说明/登录竖屏、作答/成绩横屏、底栏「下一题」横向装得下。
