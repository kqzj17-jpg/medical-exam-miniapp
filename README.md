# 模拟仿真考试系统

本地**仿真练习**微信小程序（原生 WXML/WXSS/JS，非 uni-app）。题目、成绩与登录均为演示数据，**不连接后端**。

- **说明页 / 登录页：竖屏**，微信头像、昵称与手机号授权
- **进场页：横屏**须知 → 规则 → 承诺 → 提醒（演示文案，非官方文件）
- **作答页 / 成绩页：横屏**流式机考界面（左栏约 18–20%、主栏留出间隙、题干/选项在主栏内居中，底栏两段，「上一题 / 下一题」不被挤出）

用 `env(safe-area-inset-*)` 与 `wx.getWindowInfo().safeArea` 避开刘海。不使用 transform 缩放。

## 预览方式

### A. 桌面浏览器

打开 `preview/index.html`（默认竖屏说明；`?login=1` 登录；`?notice=1` 进场须知；`?exam=1` 横屏作答）。

### B. 微信开发者工具 / 真机

1. 导入本仓库根目录，`appid` 为 **`touristappid`**
2. 说明/登录为竖屏，进入作答后横屏
3. 模拟器请分别用竖屏预览登录、横屏预览作答。**看作答页请选横屏机型，或自定义宽 > 高（如 844×390）**。用 iPhone 15 Pro 竖屏框预览横屏页时可视高度很矮，题干会被底栏挤出
4. **改代码后请重新编译；真机请重新点预览并扫码**，否则仍是旧包

无需 `npm install`。

## 登录：真实授权 vs 演示模式

登录主流程是微信能力，不再用准考证号 + 证件号。

| 步骤 | 真机（已认证小程序） | 开发工具 / tourist / 测试号 |
| --- | --- | --- |
| 头像 | `button open-type="chooseAvatar"` | 可点选；也可用演示模式跳过 |
| 昵称 | `<input type="nickname">` | 可手填；演示模式填「演示考生」 |
| 手机号 | `open-type="getPhoneNumber"`，需服务端用 `code` 换号 | 无后端无法解密。授权成功也会落到演示号，或点 **没有真机授权？点这里用演示账号** |
| 会话 | 资料写入本机 storage | 同上，界面会标「演示」 |

演示资料：昵称 `演示考生`，手机号 `13800138000`（作答页显示 `138****8000`）。点「开始练习」后先走横屏进场流程（仿真练习须知 / 规则 / 承诺 / 提醒），再进入作答。倒计时从「开始作答」起算。默认 30 分钟，可随时交卷。

## 进场流程

登录后进入横屏进场页（`pages/notice/notice`）：须知（滚到底后「已阅读确认」）→ 规则 → 勾选练习承诺 → 进场提醒对话框 → 开始作答。文案为产品内原创演示说明，并标明非正式考核。每次点「开始练习」都会再走一遍。

正式上线若要展示真实手机号，需要自建后端调用微信 `phonenumber.getPhoneNumber`；本仓库故意不接后端。

## 作答界面

- **上方**：左栏头像、昵称、脱敏手机号、剩余时间 + 题型条（当前段说明）与居中题干
- **左栏分段**：A1 / A2 / A3·A4 / B1，带连续题号范围与锁定态
- **下方**：左区标疑/跳转可换行；右区上一题、下一题始终可见；答题卡只显示**当前段**题号，题多时可纵向滚动

跨题型不可回看：进入下一段后锁定上一段，不能点已锁分段、不能上一题跨段、不能用题号跳到其他段。离开本段若有未答会再确认。交卷前展示未答汇总；成绩页可看错题回顾。
